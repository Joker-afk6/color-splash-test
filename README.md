# Color Splash — playable test build

Compiled game only (no source). Play in a desktop browser (keyboard and mouse) or on a phone or tablet held sideways (touch controls):
**https://joker-afk6.github.io/color-splash-test/**

This build: the cinematic prologue and Ruby Orchard up to Ruby's rescue (New game → choose Tarin or Mira). Continue
resumes at the last checkpoint. To start straight at Ruby's rescue:
**https://joker-afk6.github.io/color-splash-test/?at=rescue** (Tarin) or **…/?at=rescue&hero=mira** (Mira).
Controls: WASD move · mouse look (click to capture, Esc releases) · Space jump/climb · Shift dash ·
E tap with the Wonderbrush · Enter/Esc skip a cutscene · M music on/off · H controls card.
The first load downloads about 90 MB.
